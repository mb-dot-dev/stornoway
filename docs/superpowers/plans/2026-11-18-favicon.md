# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the leftover green favicon with the "b." icon (option B) as SVG, ICO and Apple touch icon.

**Architecture:** `public/favicon.svg` is the source artwork. A one-off render produces `favicon.ico` (16/32/48px PNG entries) and `apple-touch-icon.png` (180px, square corners), which are committed. `build.ts` already copies `public/` into `dist/`, so the only code changes are the `<link>` tags in both HTML pages and the build tests.

**Tech Stack:** Bun, `bun test`, headless Chrome for the one-off rasterisation.

**Spec:** `docs/superpowers/specs/2026-11-18-favicon-design.md`

## Global Constraints

- Colours: navy `#131d38`, powder `#adc7e9`, sunflower `#ffc20d`, and no others.
- No new dependencies and no build-time rasteriser.
- Link tags, in this order: `<link rel="icon" href="/favicon.ico" sizes="48x48" />`, `<link rel="icon" href="/favicon.svg" type="image/svg+xml" />`, `<link rel="apple-touch-icon" href="/apple-touch-icon.png" />`.
- No inline `<script>` or `style` attributes (CSP).

## Review Focus

- The 404 page needs the icon too. The test checks `404.html` as well as `index.html`.
- The ICO must be a valid multi-size file. Verify with `file public/favicon.ico` (expect "3 icons").
- The touch icon must have no transparent corners. iOS masks it itself, so the SVG variant uses a full-bleed rect.
